# mauriciogforero.github.io

Source for Mauricio González-Forero's personal website, built with Jekyll on GitHub Pages.

- Pages are Markdown files in the root folder (`index.md`, `research.md`, `publications.md`, `teaching.md`, `cv.md`, `funding.md`).
- The navigation bar is set in `_config.yml` under `nav`.
- The page template is `_layouts/default.html`; the styling is `assets/css/style.scss`.
